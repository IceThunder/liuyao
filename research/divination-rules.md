## 2. 起卦方法

### 2.1 铜钱法（三枚铜钱）

最常用的起卦方法。使用三枚铜钱，每枚铜钱有两面：
- **字面（有字的一面）**：为阴，记为 `2`
- **背面（无字/花纹面）**：为阳，记为 `3`

### 2.2 投掷规则

共投掷 **6次**，每次投掷三枚铜钱，从**第一次到第六次**分别对应**初爻（最下）到上爻（最上）**。

每次投掷三枚铜钱，将三枚铜钱的数值相加：

| 组合 | 数值之和 | 爻象 | 符号 | 阴阳 | 是否动爻 |
|------|---------|------|------|------|---------|
| 三个背（3+3+3） | 9 | **老阳** | ○ | 阳 | ✅ 动（阳变阴） |
| 两字一背（2+2+3） | 7 | **少阳** | — | 阳 | ❌ 静 |
| 两背一字（3+3+2） | 8 | **少阴** | -- | 阴 | ❌ 静 |
| 三个字（2+2+2） | 6 | **老阴** | × | 阴 | ✅ 动（阴变阳） |

### 2.3 爻的排列顺序

```
第6次投掷 → 上爻（第六爻）  ━━  上卦
第5次投掷 → 五爻            ━━  上卦
第4次投掷 → 四爻            ━━  上卦
第3次投掷 → 三爻            ━━  下卦
第2次投掷 → 二爻            ━━  下卦
第1次投掷 → 初爻（第一爻）  ━━  下卦
```

- 下三爻组成**下卦（内卦）**
- 上三爻组成**上卦（外卦）**

### 2.4 编程实现要点

```
输入：6次投掷结果，每次为 [6, 7, 8, 9] 之一
输出：
  - 本卦（6个爻的阴阳状态）
  - 动爻位置（值为6或9的爻）
  - 变卦（动爻变化后的卦）
  
映射：
  6 → 阴，动爻（变阳）
  7 → 阳，静爻
  8 → 阴，静爻
  9 → 阳，动爻（变阴）
```

### 5.2 世爻与应爻

世爻代表自己，应爻代表对方/事物。世应的位置由卦在八宫中的位置决定。

#### 5.2.1 世应对照表

| 卦序 | 名称 | 世爻位置 | 应爻位置 |
|------|------|---------|---------|
| 本宫卦（纯卦） | 八纯卦 | 第六爻（上爻） | 第三爻 |
| 一世卦 | | 第一爻（初爻） | 第四爻 |
| 二世卦 | | 第二爻 | 第五爻 |
| 三世卦 | | 第三爻 | 第六爻（上爻） |
| 四世卦 | | 第四爻 | 第一爻（初爻） |
| 五世卦 | | 第五爻 | 第二爻 |
| 游魂卦 | | 第四爻 | 第一爻（初爻） |
| 归魂卦 | | 第三爻 | 第六爻（上爻） |

#### 5.2.2 规律总结

- **世应相隔三位**（世在第N爻，应在第N+3爻，超过6则减6）
- 本宫卦世在上爻（6），一世到五世依次为1-5，游魂回到4，归魂回到3

### 5.3 六亲

六亲是根据**卦宫五行**与**各爻地支五行**之间的生克关系来确定的。

#### 5.3.1 六亲确定规则

以**卦所属宫的五行**为"我"，各爻地支的五行为"他"：

| 关系 | 六亲名称 | 说明 |
|------|---------|------|
| 生我者 | **父母** | 他生我 |
| 我生者 | **子孙** | 我生他 |
| 克我者 | **官鬼** | 他克我 |
| 我克者 | **妻财** | 我克他 |
| 同我者 | **兄弟** | 五行相同 |

#### 5.3.2 五行生克速查表（以宫五行为"我"）

| 宫五行＼爻五行 | 金 | 木 | 水 | 火 | 土 |
|---------------|----|----|----|----|-----|
| **金（乾兑宫）** | 兄弟 | 妻财 | 子孙 | 官鬼 | 父母 |
| **木（震巽宫）** | 官鬼 | 兄弟 | 父母 | 子孙 | 妻财 |
| **水（坎宫）** | 父母 | 子孙 | 兄弟 | 妻财 | 官鬼 |
| **火（离宫）** | 妻财 | 父母 | 官鬼 | 兄弟 | 子孙 |
| **土（艮坤宫）** | 子孙 | 官鬼 | 妻财 | 父母 | 兄弟 |

#### 5.3.3 六亲装卦示例

以**天风姤**为例，属**乾宫**，宫五行为**金**：

```
上爻：壬戌（土）→ 土生金 → 父母
五爻：壬申（金）→ 金同金 → 兄弟  ← 世爻
四爻：壬午（火）→ 火克金 → 官鬼
三爻：辛酉（金）→ 金同金 → 兄弟
二爻：辛亥（水）→ 金生水 → 子孙  ← 应爻
初爻：辛丑（土）→ 土生金 → 父母
```

### 5.4 六神（六兽）

六神从上到下依次排列在六爻旁边，用于辅助判断事物的性质和吉凶。

#### 5.4.1 六神排列规则

六神的起始位置由**占卜当日的天干**决定：

| 日天干 | 初爻起 |
|--------|--------|
| 甲、乙 | 青龙 |
| 丙、丁 | 朱雀 |
| 戊 | 勾陈 |
| 己 | 螣蛇 |
| 庚、辛 | 白虎 |
| 壬、癸 | 玄武 |

#### 5.4.2 六神固定顺序（循环）

```
青龙(1) → 朱雀(2) → 勾陈(3) → 螣蛇(4) → 白虎(5) → 玄武(6)
```

从**初爻**开始，按上述顺序依次向上排到**上爻**，超出则循环。

#### 5.4.3 示例（丙日，初爻起朱雀）

```
上爻：青龙  （朱雀→勾陈→螣蛇→白虎→玄武→青龙）
五爻：玄武
四爻：白虎
三爻：螣蛇
二爻：勾陈
初爻：朱雀  ← 起始
```

## 6. 动爻与变卦

### 6.1 动爻的产生

在起卦时，投掷结果为 **6（老阴）** 或 **9（老阳）** 的爻称为**动爻**。

- **老阳（9）**：阳爻发动，变为阴爻
- **老阴（6）**：阴爻发动，变为阳爻
- **少阳（7）**：阳爻不动（静爻）
- **少阴（8）**：阴爻不动（静爻）

### 6.2 变卦的生成

将本卦中所有动爻变化后，得到的新卦即为**变卦**。

```
规则：
  本卦动爻为老阳(9) → 变卦该位置变为阴爻
  本卦动爻为老阴(6) → 变卦该位置变为阳爻
  本卦静爻(7或8)   → 变卦该位置不变
```

### 6.3 变爻的纳甲

变卦也需要装纳甲地支。变卦的纳甲按照变卦自身的上下卦来装，与本卦无关。

### 6.4 动爻与变爻的六亲

- **动爻的六亲**：按本卦所属宫的五行来定
- **变爻的六亲**：也按**本卦**所属宫的五行来定（不是变卦的宫）

### 6.5 示例

本卦：天风姤（乾宫），假设初爻动（老阴6）：

```
本卦：天风姤          变卦：天山遁
上爻：壬戌 父母        上爻：壬戌 父母
五爻：壬申 兄弟 世      五爻：壬申 兄弟
四爻：壬午 官鬼        四爻：壬午 官鬼
三爻：辛酉 兄弟        三爻：丙申 兄弟
二爻：辛亥 子孙 应      二爻：丙午 官鬼
初爻：辛丑 父母 ×动    初爻：丙辰 父母  ← 变爻
```

> 初爻老阴发动，阴变阳。下卦由巽变为艮，变卦为天山遁。

### 6.6 多爻同动

一卦中可以有0-6个动爻。多爻同动时，所有动爻同时变化生成变卦。

## 7. 断卦基础逻辑

### 7.1 用神的选取

用神是断卦的核心，根据求测事项选取对应的六亲作为用神：

| 求测事项 | 用神（六亲） | 说明 |
|---------|-------------|------|
| 父母、长辈 | 父母 | 测父母健康、运势 |
| 学业、考试 | 父母 | 父母主文书、学业 |
| 房屋、车辆 | 父母 | 父母主庇护之物 |
| 文书、合同 | 父母 | 父母主文书契约 |
| 兄弟、朋友 | 兄弟 | 测同辈关系 |
| 子女 | 子孙 | 测子女运势 |
| 求财 | 妻财 | 财运、收入 |
| 妻子、女友 | 妻财 | 测感情（男测女） |
| 工作、官职 | 官鬼 | 测事业、升迁 |
| 丈夫、男友 | 官鬼 | 测感情（女测男） |

### 7.2 旺衰判断

爻的旺衰由**月建**（占卜月份的地支）和**日辰**（占卜日的地支）决定。

#### 7.2.1 月建对爻的影响

月建地支的五行与爻地支五行的关系：

| 关系 | 状态 | 说明 |
|------|------|------|
| 月建生爻 | **月生** | 爻得月建之生，旺 |
| 月建与爻同五行 | **月旺（临月建）** | 爻临月建，最旺 |
| 爻生月建 | **月泄** | 爻被月建泄气，稍弱 |
| 爻克月建 | **月耗** | 爻克月建耗力，稍弱 |
| 月建克爻 | **月克** | 爻被月建所克，弱 |

#### 7.2.2 月建旺相休囚死

根据当月地支五行，判断各五行的旺衰状态：

| 月令五行 | 旺 | 相 | 休 | 囚 | 死 |
|---------|----|----|----|----|-----|
| 春（寅卯月/木） | 木 | 火 | 水 | 金 | 土 |
| 夏（巳午月/火） | 火 | 土 | 木 | 水 | 金 |
| 四季（辰未戌丑月/土） | 土 | 金 | 火 | 木 | 水 |
| 秋（申酉月/金） | 金 | 水 | 土 | 火 | 木 |
| 冬（亥子月/水） | 水 | 木 | 金 | 土 | 火 |

> **旺相**为有力，**休囚死**为无力。
